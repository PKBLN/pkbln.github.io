# PKBLN — Persönliche GitHub Pages

Diese Seite dient als einfache persönliche Startseite, die auf meine öffentlichen Projekte verweist. Die Seite ist zweisprachig (DE/EN).

Die Startseite `index.html` lädt `projects.json`, das eine Liste der öffentlichen Repositories enthält.

Inhalt:
- index.html — zweisprachige Startseite
- projects.json — automatisch erzeugte Liste öffentlicher Repositories

Hosted on GitHub Pages: https://pkbln.github.io/
